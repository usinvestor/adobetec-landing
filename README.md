## How to Use

1. **Deploy to Vercel** (Recommended - Free)
   - Push this repo to GitHub
   - Go to vercel.com
   - Import your GitHub repository
   - Deploy in 1 click

2. **Deploy to Netlify** (Also Free)
   - Push this repo to GitHub
   - Go to netlify.com
   - Drag and drop the folder or connect GitHub

3. **Custom Domain**
   - After deployment, add a custom domain
   - Cost: $12/year for domain name

## Customization

### Change Business Information
Edit `index.html` footer section:
```html
<p>Email: <a href="mailto:your-email@adobetec.com">your-email@adobetec.com</a></p>
<p>Phone: <a href="tel:+1-your-phone">+1 (Your Phone)</a></p>
```

### Update Pricing
Edit the pricing cards in `index.html` to adjust prices and features.

### Change Colors
Edit `styles.css` gradient colors:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Add Your Logo
Replace the "Adobetec" text in the navbar with an image tag.

## Form Data Storage

Lead form submissions are currently stored in browser localStorage. For production, integrate with:

- **Email Service**: Mailchimp, ActiveCampaign, Klaviyo
- **CRM**: Pipedrive, HubSpot, Airtable
- **Webhook**: Make.com, Zapier, or custom backend
