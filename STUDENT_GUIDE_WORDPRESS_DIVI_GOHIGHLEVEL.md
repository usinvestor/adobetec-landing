## 🛠️ Step-by-Step Setup Guide

### **SETUP #1: GoHighLevel Embed Code (Start Here!)**

#### **Step 1: Create GoHighLevel Account**
1. Go to https://www.gohighlevel.com
2. Click "Start Free Trial" (14 days free)
3. Sign up with your email
4. Choose **Unlimited Plan** ($297/month) to get unlimited clients
5. Complete onboarding

#### **Step 2: Create Lead Capture Form in GoHighLevel**
1. Log into GoHighLevel dashboard
2. Go to **"Forms & Surveys"** (left sidebar)
3. Click **"Create Form"**
4. Add fields:
   - Full Name (required)
   - Email (required)
   - Phone (required)
   - Business Name (optional)
   - Message (optional)
5. Customize styling to match your brand
6. Click **"Save & Publish"**
7. Click **"Get Embed Code"**
8. Copy the code (looks like: `<iframe src="...">`)

#### **Step 3: Add Form to WordPress Divi**
1. Open your WordPress page in **Divi Builder**
2. Add a new section where you want the form
3. Add a module: **"Code"** (or **"Custom HTML"**)
4. Paste the GoHighLevel embed code
5. Click **"Save"**
6. Preview page
7. **DONE!** Form now appears on your website

#### **Step 4: Test the Form**
1. Fill out the form with test data
2. Log into GoHighLevel
3. Go to **"Contacts"** in CRM
4. Verify the lead was captured
5. **Success!** Leads now flow to GoHighLevel

#### **Step 5: Set Up Lead Pipeline (Automation)**
1. In GoHighLevel, go to **"Pipelines"**
2. Create a new pipeline called "Lead Funnel"
3. Add stages:
   - **New Lead** (form submission)
   - **Contacted** (you reached out)
   - **Qualified** (interested)
   - **Proposal Sent**
   - **Customer** (won deal)
4. Move leads through pipeline as you communicate

#### **Step 6: Create Email Automation Sequence**
1. Go to **"Automations"** in GoHighLevel
2. Click **"New Automation"**
3. Set trigger: **"Form Submission"**
4. Select your form
5. Add first email:
   - **Subject:** "Thank You! Here's What Happens Next"
   - **Body:** Welcome message + next steps
6. Add delay: **"Wait 1 day"**
7. Add second email:
   - **Subject:** "Let's Schedule Your Consultation"
   - **Body:** Call to action + booking link
8. Save automation
9. **DONE!** Leads get auto-replied!

### **SETUP #2: WPForms + Zapier Integration (Advanced)**

#### **What You Need:**
- WPForms plugin ($39-99/year)
- Zapier account ($20-50/month)
- GoHighLevel account (already set up)

#### **Step 1: Install WPForms**
1. Go to WordPress **Plugins** → **Add New**
2. Search for **"WPForms"**
3. Install and activate
4. Get license key from WPForms.com
5. Paste in WordPress settings

#### **Step 2: Create Form in WordPress**
1. Go to **WPForms** → **Add New**
2. Choose template: **"Contact Form"**
3. Add fields:
   - Full Name
   - Email
   - Phone
   - Message
4. Customize design
5. Click **"Save"**

#### **Step 3: Add Form to Divi**
1. Open Divi Builder
2. Add a section
3. Add **"WPForms"** module
4. Select your form
5. Save and preview

#### **Step 4: Connect WPForms to GoHighLevel with Zapier**
1. Go to https://zapier.com
2. Sign up / Log in
3. Click **"Create Zap"**
4. **Trigger:** Search "WPForms" → Select "New Entry"
5. Connect your WordPress site
6. Select your form
7. **Action:** Search "GoHighLevel" → Select "Create Contact"
8. Connect your GoHighLevel account
9. Map fields:
   - WPForms Name → GoHighLevel First Name
   - WPForms Email → GoHighLevel Email
   - WPForms Phone → GoHighLevel Phone
10. Click **"Test & Continue"**
11. Turn on the Zap

#### **Step 5: Test It**
1. Fill out your WordPress form
2. Check GoHighLevel CRM
3. Lead should appear in 1-2 minutes
4. **Success!**
